Question 7: cURL command and output confirming successful registration of a new user (plus other registration cases)

1) Successful registration of a new user

Command:

curl -s -X POST http://localhost:5000/register -H "Content-Type: application/json" -d '{"username":"john_doe","password":"secret123"}'

Output:

{"message":"User successfully registered. Now you can login"}

2) Registering the same username again (already registered case)

Command:

curl -s -X POST http://localhost:5000/register -H "Content-Type: application/json" -d '{"username":"john_doe","password":"secret123"}'

Output:

{"message":"Username already registered"}

3) Registering without username or password (failure case)

Command:

curl -s -X POST http://localhost:5000/register -H "Content-Type: application/json" -d '{"username":"john_doe"}'

Output:

{"message":"Username or Password not provided"}
